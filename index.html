多 AI 工作台 · 本地版 V1

ChatGPT / WorkBuddy / Grok / Muse / 豆包 / 百度搭子 —— 一个界面管任务、提示词和资源，零 API 成本，数据只存在本机。

单用户本地 localStorage手动复制粘贴不上传、不追踪

任务板

6 步工作流：第 1 步在这里建任务 → 第 2 步选提示词填变量 → 第 3 步去启动器打开对应 AI → 第 4 步手动粘贴、拿到产出 → 第 5 步把产出存进资源中心 → 第 6 步在额度本记一次用量。任务里的“提示词快照”方便复盘这篇产出用的哪版提示词。

AI 启动器

点卡片打开对应平台官网（新标签页）。“复制当前任务简报”会把当前选中的任务（默认第一个进行中的任务）拼成一段简报，粘贴到 AI 对话框里直接用。桌面客户端路径只能复制，不能从网页直接启动 exe——这是浏览器的安全限制，不是 bug，路径在“额度本与设置”里改。

提示词库

共 11 条：附录 B 通用模板 3 条（产品文案改写 / 配图生成 / 跨 AI 续作交接）+ D4 模板 4–9 + 跨 AI 背景交接导出/导入 2 条。点一条模板，下面会出现 {变量} 填空，填完点“复制填好后的提示词”。示例产品名仅为示例，不含编造的产品参数。

资源中心

产出统一存这里：哪个 AI 出的、什么类型、打什么标签、文件在本地哪里。只记“路径/位置”文字，不上传文件本身。

额度本（手动记）

只用现有免费订阅点数/额度，不走 API 付费。各平台免费额度以官网为准，这里只是你自己每天手动记的账本，不会自动同步。

桌面客户端路径（可编辑，待你核对）

WorkBuddy 默认路径来自 D3 定位指南的公开资料，尚未经你本机核对，请按你电脑上的实际路径改。豆包路径请按你本机实际填写；百度搭子（DuMate）以网页版为主，未找到可信的默认安装路径，不编造。改完点保存，只存在本机。

数据备份

所有数据都在浏览器 localStorage 里。换电脑、清浏览器数据会丢失，记得定期导出 JSON 备份。
